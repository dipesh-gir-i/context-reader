# Contributing

## Setup
npm ci
npm run typecheck
npm run build

## Branches
main        -> stable
develop     -> integration
feature/*   -> new features
fix/*       -> bug fixes

## Commits
feat: ...
fix: ...
docs: ...
refactor: ...
test: ...

## Pull Requests
- Explain what changed
- Include screenshots for UI changes
- Ensure typecheck passes
- Ensure build passes
- Do not commit API keys
